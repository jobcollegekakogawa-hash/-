# 契約書動画説明アプリ プロトタイプ

契約書データを入力すると、重要ポイントを抽出して「説明動画風」のスライドとして表示する静的Webアプリです。最後の署名は電子署名ではなく、紙の契約書へ直筆署名していただく運用を想定しています。

## 機能

- 契約書テキストの貼り付け
- `.txt` ファイルの読み込み
- `.doc` / `.docx` の読込時に `.txt` へ変換して保存
- 契約期間、金額、通知期限、守秘義務、解除条件などの説明スライド生成
- 再生・停止・前へ・次への動画風操作
- 重要部分を日本語音声ガイド（SpeechSynthesis）で読み上げ
- 音声ガイドは少しゆっくり（rate: 0.85）で読み上げ
- `**太文字**` や `<b>太文字</b>` で強調した条項を抽出し、優先して読み上げ
- スライドにイラストを入れた説明動画を再生
- 重要度ラベルと音声ガイド文（字幕）を動画フレームに表示
- 説明スライドからWebM形式の動画データを生成・ダウンロード
- 説明後の確認チェックリスト
- 直筆署名へ進む案内

## 起動方法

```bash
npm start
```

サーバーは `0.0.0.0:4173` で起動します。この環境のブラウザプレビューでは、ポート `4173` の転送URLを開いてください。ローカルPCで実行する場合は <http://localhost:4173> を開きます。

## プレビューURLを使えない場合

```bash
npm run build
```

`dist/contract-video-explainer.html` にCSSとJavaScriptを埋め込んだ単一HTML版を生成します。このファイルをブラウザで直接開くと、サーバーなしで契約書テキスト入力、説明スライド生成、WebM動画データのダウンロードを試せます。


## `dist/contract-video-explainer.html` をダウンロード／ブラウザで開く方法

### 方法1: この作業環境のファイル一覧からダウンロードする

1. 左側のファイル一覧で `dist` フォルダを開きます。
2. `contract-video-explainer.html` を選択します。
3. エディタ右上またはファイルメニューの **Download** / **ダウンロード** を押して、PCへ保存します。
4. 保存した `contract-video-explainer.html` をダブルクリックすると、ChromeやEdgeなどのブラウザで開けます。

### 方法2: ターミナルから場所を確認して開く

このリポジトリ内では、ファイルは次の場所にあります。

```text
/workspace/-/dist/contract-video-explainer.html
```

ローカルPCへコピーできる環境では、このHTMLファイルを任意のフォルダへ保存してから、ブラウザへドラッグ＆ドロップするか、ダブルクリックして開いてください。

### 方法3: サーバー経由で開く

```bash
npm start
```

起動後、ポートプレビュー機能がある環境では **port 4173** を開き、次のパスへアクセスします。

```text
/dist/contract-video-explainer.html
```

ローカルPC上で起動している場合は、次のURLを開きます。

```text
http://localhost:4173/dist/contract-video-explainer.html
```

表示されたページを保存したい場合は、ブラウザで **Ctrl+S**（Macは **Command+S**）を押してHTMLとして保存できます。

## 動画データの書き出し

デモ画面で契約書のプレーンテキストを入力し、「動画データを書き出す」を押すと、現在の入力内容から説明スライドを作成し、ブラウザ上でWebM形式の動画データを生成します。生成完了後は `contract-explanation-YYYYMMDD-HHMMSS.webm` のダウンロードが自動で開始され、開始しない場合は表示されるリンクから手動でダウンロードできます。

動画生成にはCanvas Capture APIとMediaRecorder APIを使うため、対応ブラウザ（Chrome、Edgeなど）で利用してください。

音声ガイドはブラウザのSpeechSynthesis APIを利用します。環境によっては動画ファイル自体に音声は含まれず、アプリ再生時の読み上げとして提供されます。

Wordファイル（`.doc` / `.docx`）を選択すると、アプリ内テキスト化結果を `.txt` としてダウンロードできます。

## 注意

このプロトタイプは契約理解の補助を目的としたデモです。法的助言や電子署名機能は含みません。実運用では、契約書解析の精度検証、個人情報保護、監査ログ、同意記録、弁護士・専門家レビュー導線などを追加してください。
