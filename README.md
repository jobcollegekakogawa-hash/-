# やさしいサポート提案（シンプル試作品）

子どもの困りごとを選ぶと、**おすすめの関わり方を3つ表示**する、スマホ向けのシンプルなWebアプリです。

## できること

- 困りごとを選択
  - 大きな音が苦手
  - 人が多い場所が苦手
  - 切り替えが苦手
  - パニックになる
  - 場面緘黙
- おすすめの関わり方を3つ表示

---

## はじめて使う人向け（いちばん簡単な手順）

### 1) 準備

このフォルダでターミナルを開きます。

### 2) アプリを起動

```bash
npm start
```

### 3) ブラウザで開く

- ローカルPCなら: <http://localhost:4173>
- この環境のプレビュー機能を使う場合は、**4173番ポート**を開いてください。

---

## 使い方

1. 「困りごとを選んでください」で項目を選びます。
2. 「おすすめを見る」を押します（選んだ時点でも自動表示されます）。
3. おすすめ3つが表示されます。

---

## ファイル構成（初心者向け）

- `index.html` : 画面の見た目（文字やボタンの配置）
- `styles.css` : 色や余白などのデザイン
- `app.js` : 選んだ困りごとに応じておすすめを表示する処理

---

## うまくいかないとき

- `npm start` でエラーが出たら、先に次を実行してください。

```bash
npm install
```

そのあと、もう一度 `npm start` を実行します。

---

## 注意

この試作品は、日常の関わり方のヒントを出すためのものです。診断や医療的な判断を行うものではありません。
